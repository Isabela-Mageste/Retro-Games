# Testes unitários

Projeto xUnit v3 com Moq e referências exigidas. Sem testes artificiais de propriedades: a Aula 1 solicita testes SQL de integridade, disponíveis em database/. Os testes de controllers, services e validators serão acrescentados quando esses componentes forem implementados. Execute `dotnet run --project RetroGames.WebApi.UnitTests` para usar o runner nativo do xUnit v3. Não interprete ausência de testes como validação do sistema.
